# Dog Gallery Project

## Overview
This is a static website displaying a gallery of adorable dog and cat photos. The project was imported from GitHub and set up to run in the Replit environment.

## Project Structure
- `index.html` - Main HTML page with gallery layout
- `style.css` - Responsive CSS styling with gradient background and hover effects
- `server.py` - Python HTTP server configured to serve static files on port 5000
- `images/` - Directory containing 8 pet photos (dogs and cats)

## Technology Stack
- HTML5
- CSS3 (with responsive grid layout)
- Python 3.11 (HTTP server)

## Setup Date
November 25, 2025

## Features
- Responsive grid layout that adapts to different screen sizes
- Modern gradient background
- Hover effects on gallery items
- Mobile-friendly design
- Cache-control headers to ensure fresh content delivery

## Running the Project
The project runs automatically via the "Web Server" workflow which executes `python server.py` on port 5000. The server binds to 0.0.0.0 to be accessible through Replit's preview system.
